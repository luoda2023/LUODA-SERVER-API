# LUODA 后台使用说明

## 访问入口

- 后台地址：http://106.54.219.147:21114/_admin/
- 域名地址：http://LD.DICAD.CN:21114/_admin/
- API 前缀：`/api/admin`

## 登录后台

1. 打开后台地址。
2. 输入管理员账号和密码。
3. 登录成功后进入管理首页。

如果提示账号或密码错误，先确认使用的是后台管理员账号，不是客户端设备 ID 或设备密码。

## 用户管理

后台左侧菜单进入“用户管理”。这里用于给客户创建网页登录账号，并设置或修改客户登录密码。

常用操作：

- 新增用户：填写用户名、昵称、邮箱、用户组、是否管理员、状态和初始密码。
- 编辑用户：修改客户资料、权限、状态、分组等信息。
- 改密：单独修改客户网页登录密码。
- 删除用户：删除不再使用的客户账号。

对应接口：

- 用户列表：`GET /api/admin/user/list`
- 用户详情：`GET /api/admin/user/detail/:id`
- 新增用户：`POST /api/admin/user/create`
- 编辑用户：`POST /api/admin/user/update`
- 修改密码：`POST /api/admin/user/changePwd`
- 删除用户：`POST /api/admin/user/delete`

## 设备管理

后台左侧菜单进入“设备管理”。这里查看已经接入服务器的设备信息，包括设备 ID、主机名、平台、归属用户、状态和更新时间。

## 连接记录

后台左侧菜单进入“连接记录”。这里查看设备连接调用记录，用于排查 A、B 设备访问情况。

当前记录字段包含：

- 设备 ID
- 用户 ID
- 连接类型
- 连接状态
- 开始时间
- 结束时间
- 客户端 IP
- 对端 IP
- 客户端名称
- 对端名称

## 登录令牌

后台左侧菜单进入“登录令牌”。这里查看用户网页登录后生成的令牌记录，可用于排查登录状态。

## 服务器配置

后台左侧菜单进入“服务器配置”。这里查看 ID Server、Relay Server、API Server、公钥和 Web 客户端相关配置。

不要随意修改服务器密钥。VPS 上 `/data/id_ed25519` 和 `/data/id_ed25519.pub` 是关键文件，必须保持稳定。

## 常见问题

### 客户登录账号在哪里设置？

在后台“用户管理”中新增用户或修改密码。

### API 登录接口在哪里？

网页登录接口是：`POST /api/admin/login`。

请求示例：

```json
{
  "username": "admin",
  "password": "your-password"
}
```

### 修改客户密码使用哪个接口？

使用：`POST /api/admin/user/changePwd`。

请求示例：

```json
{
  "id": 2,
  "password": "new-password"
}
```

### 后台图标不显示怎么办？

先强制刷新浏览器缓存。图标文件在后台资源目录：`/_admin/assets/icons/`。

### 菜单看起来仍然不紧凑怎么办？

先强制刷新浏览器缓存，确保加载的是最新 `/_admin/assets/admin.css`。
