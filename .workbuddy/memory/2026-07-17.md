# 2026-07-17

## LUODA 管理后台修复

### 1. Token 过期自动跳转登录页
- **问题**: admin.js 第 330 行 `if (state.token) { setView(true); ... }` 只检查 localStorage 有无 token 字符串，不验证是否过期。token 过期后仍加载 dashboard，导致白屏卡住
- **修复**: 在显示 dashboard 前调用 `request("/config/server")` 做轻量 token 校验，无效则清除 localStorage 并回退到登录界面
- **文件**: `api/resources/admin/assets/admin.js`（本地 + VPS `/root/luoda-data/resources/admin/assets/admin.js` 同步更新）

### 2. 连接记录空值说明
- 用户发现连接记录中部分记录的 from_name/from_peer 为空、session_id=0
- 原因是互联网扫描器/爬虫探测中继端口，未经完整认证握手就被拒绝，审计日志留下残缺记录
- 非安全问题，属于正常现象
